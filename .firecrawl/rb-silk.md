## Props

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `speed` | number | `5` | Controls the animation speed of the silk effect. |
| `scale` | number | `1` | Controls the scale of the silk pattern. |
| `color` | string | `'#7B7481'` | Hex color code for the silk pattern. |
| `noiseIntensity` | number | `1.5` | Controls the intensity of the noise effect. |
| `rotation` | number | `0` | Controls the rotation of the silk pattern (in radians). |

`speed`number

Controls the animation speed of the silk effect.

Default`5`

`scale`number

Controls the scale of the silk pattern.

Default`1`

`color`string

Hex color code for the silk pattern.

Default`'#7B7481'`

`noiseIntensity`number

Controls the intensity of the noise effect.

Default`1.5`

`rotation`number

Controls the rotation of the silk pattern (in radians).

Default`0`
